# ToDou bundled fonts

`LXGWNeoXiHeiScreenFull.ttf` is the full screen-reading build of LXGW Neo XiHei (霞鹜新晰黑 屏幕阅读版), bundled so the UI can render Chinese text when the operating system does not have the font installed.

`SpaceGrotesk-wght.ttf`, `SpaceMono-Regular.ttf`, and `SpaceMono-Bold.ttf` are bundled so the UI does not depend on Google Fonts at runtime.

`Doto-ROND-wght.ttf` is bundled for the Nothing-style dot-matrix display used by the open-item count in the top bar. It is the variable Doto font with `ROND` and `wght` axes.
